Privacy Policy

Hermes Personal Assistant · Last updated 23 October 2026

Who uses Hermes

Hermes is a private assistant used by one person, its owner, with his own Google accounts. It is not offered to anyone else.

What Google data it uses

  • Gmail: to read new mail, apply labels, move mail to folders, mark mail as read, and prepare summaries for the owner.
  • Google Calendar: to read upcoming events and remind the owner of them.

Where the data stays

All data is processed and stored only on the owner's own computer. It is not uploaded to any server run by Hermes, and it is not sent to cloud AI services. The AI models Hermes uses run on the owner's computer.

Sharing

Google user data is not sold, rented, or shared with anyone. It is not used for advertising.

Google API Services User Data Policy

Hermes's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Data kept on the owner's computer can be deleted by the owner at any time.
